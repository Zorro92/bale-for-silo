# Bale

A native Xbox client for [Silo](https://siloserver.org), the self-hosted media server.

Bale is an independent, community project. It is not affiliated with or endorsed by the Silo
project. *Silo* and the Silo logo are trademarks of Silo Media L.L.C.

> **Status:** first milestone. Bale can pair with a Silo server using a sign-in code and
> remember the session. Browsing and playback come next.

## How it's built

| Part | What it is | Builds on |
|---|---|---|
| `src/Bale.Core` | Silo API client (generated from Silo's OpenAPI contract), sign-in, session handling | Linux, macOS, Windows |
| `tests/Bale.Core.Tests` | Unit tests for Core | Linux, macOS, Windows |
| `tools/Bale.Cli` | Developer tool that runs Core against a real server | Linux, macOS, Windows |
| `src/Bale.Xbox` | The Xbox app: UWP on .NET 10 with Native AOT | Windows (CI does this for you) |

Keep logic in `Bale.Core` wherever possible so it can be developed and tested without Windows.

## Developing on Linux

You need the [.NET 10 SDK](https://dotnet.microsoft.com/download), `gh`, `curl` and `jq`.

```sh
dotnet test tests/Bale.Core.Tests

# Try sign-in against your own server: prints a code to approve in Silo.
dotnet run --project tools/Bale.Cli -- login https://silo.example.com
```

### Updating the Silo API client

The client in `src/Bale.Core/Api` is generated by [Kiota](https://learn.microsoft.com/openapi/kiota/)
from `contracts/api/v2/openapi.json` in
[Silo-Server/silo-server](https://github.com/Silo-Server/silo-server), pinned to a commit in
`scripts/generate-api.sh`. To use a new endpoint, add an `--include-path` line there and run:

```sh
./scripts/generate-api.sh
```

Don't edit the generated files by hand.

## Running on an Xbox

1. Put the console in [Developer Mode](https://learn.microsoft.com/windows/uwp/xbox-apps/devkit-activation)
   and turn on Device Portal in Dev Home.
2. Push to `main`. CI builds a signed `.msix` on a Windows runner.
3. Install and launch the newest build from Linux:

   ```sh
   XBOX_HOST=<your Xbox IP> ./scripts/deploy-xbox.sh
   ```

   Add `XBOX_USER` and `XBOX_PASS` if Device Portal asks for a login.
