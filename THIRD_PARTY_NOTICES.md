## FFmpegInteropX

All Bale builds bundle modified [FFmpegInteropX.UWP.Lib](https://github.com/Zorro92/bale-ffmpeginteropx)
**2.1.0-bale.26**, a Bale x64 native-wrapper fork of upstream 2.1.0, under **Apache-2.0**.
Its full license text is packaged as `Licenses/FFmpegInteropX.txt`
(source copy: `src/Bale.Xbox/Assets/FFmpegInteropX-LICENSE.txt`). Corresponding source is at
[Zorro92/bale-ffmpeginteropx](https://github.com/Zorro92/bale-ffmpeginteropx), pinned to commit
`d3956a2998f120d6817e7a996dbf2c807887c68f`. The former 22-patch Bale series is preserved there
as commits, including upstream PR #482's colour-attribute fix, decode-ahead tuning, GPU grain and
zero-copy AV1 delivery, system Dolby decoding and bitmap subtitle delivery to Bale's overlay.
The fork also fixes HDR metadata and display-matrix reads to use the side-data payload.
Version bale.25 adds the opt-in PQ P010 → SDR NV12 tone-map stage, using Bale tone-map ABI 1;
it is disabled unless the debug-only bale_tonemap key is set. Version bale.26 adds opt-in
compressed system-decoder colour/HDR attributes; bale_compressed_color_info remains unset in production.
Grain only modifies Bale-owned output, never dav1d reference frames. The original winmd, managed
projection and x86/ARM64 payloads are retained; only x64 is built from the modified source.
With the `bale_*` keys unset, behavior equals upstream 2.1.0 plus the colour-attribute and
side-data payload fixes.

The [wrapper release](https://github.com/Zorro92/bale-ffmpeginteropx/releases/tag/wrapper-ffmpeginteropx-2.1.0-bale.26)
provides the nupkg, SHA256, `SOURCES.txt`, metadata comparison, build log and corresponding source
archive. Provenance records the fork/source commit, native dependency and build tools; it ships
in all MSIX builds as `Licenses/FFmpegInteropX/SOURCES.txt`. The release repository, tag, source
commit and expected package hashes are pinned in `scripts/ffmpeginteropx-wrapper.json`;
build/integration details are in `docs/player-plan.md` and the fork's
[`bale/README.md`](https://github.com/Zorro92/bale-ffmpeginteropx/blob/main/bale/README.md).
Bale remains AGPL-3.0-or-later; third-party components retain their own licenses.

## FFmpeg

All builds bundle the UWP x64 package **FFmpegInteropX.UWP.FFmpeg
8.1.2-bale.dav1d.1.5.4.p1**, rebuilt by Bale to update dav1d and apply one reviewed
`libavcodec/libdav1d.c` patch (patch set p1: an opt-in for caller-supplied picture memory,
listed with its SHA256 in `SOURCES.txt`). The **bundled x64 build is LGPL-2.1-or-later**, not a GPL/nonfree FFmpeg build: its `avutil-60.dll` configuration contains
`--disable-gpl`, `--disable-version3` and `--disable-encoders`, and its license string is
`LGPL version 2.1 or later`. Neither x264 nor x265 is built or linked. The package's
`licenses/ffmpeg.txt` is the LGPL 2.1 text, shipped as `Licenses/FFmpeg/ffmpeg.txt`.
It remains a shared-library build (`--enable-shared`), including `--enable-libdav1d`.

FFmpeg remains at `38b88335f99e76ed89ff3c93f877fdefce736c13`. The build baseline is
[FFmpegInteropX v2.1.0, commit 88428c66e106852338b48554a4a00c9e48da588f](https://github.com/ffmpeginteropx/FFmpegInteropX/tree/88428c66e106852338b48554a4a00c9e48da588f),
with its other dependency revisions and FFmpeg configure flags unchanged. The x64-only NuGet
omits unused architecture globs and adds provenance; the separately rebuilt interop wrapper is
2.1.0-bale.26 as described above.

The [native release](https://github.com/Zorro92/bale-for-silo/releases/tag/native-ffmpeg-8.1.2-dav1d-1.5.4-p1)
provides the package, SHA256, `SOURCES.txt` with every submodule revision and build parameters,
and `ffmpeg-native-sources.tar.gz` containing corresponding source for all built dependencies.
Provenance also ships in the NuGet and MSIX (`Licenses/FFmpeg/SOURCES.txt`). The expected package
hash is pinned in `scripts/ffmpeg-native.json`; rebuild instructions are in `docs/player-plan.md`.
Other bundled dependencies (bzip2, iconv, liblzma, libxml2, OpenSSL and zlib) retain their respective
license texts, all packaged under `Licenses/FFmpeg/` regardless of `BaleDebugServer`.

## dav1d

The FFmpeg package statically links [dav1d](https://code.videolan.org/videolan/dav1d) **1.5.4**
(commit `54706fc6bc0cdecab7e9593974a4039cc038fca7`), the software AV1 decoder, under the
BSD 2-Clause License. CI checks the version embedded in the actual packaged `avcodec-62.dll`.

Copyright © 2018–2025, VideoLAN and dav1d authors. All rights reserved.

The full bundled notice and license are shipped as `Licenses/FFmpeg/dav1d.txt` in every build.

The CPU AV1 film-grain implementation in `native/bale-gpu/src/grain` and integer GPU grain shaders
in `native/bale-gpu/shaders` also port this dav1d revision's `filmgrain_tmpl.c`, `fg_apply_tmpl.c` and
Gaussian sequence in `tables.c`. Ported files retain the original copyright notices and full BSD
2-Clause licence text; `native/bale-gpu/NOTICE` records their provenance. The wrapper applies grain
only through the GPU shaders; the CPU port is kept as their test and self-check reference.
